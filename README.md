# Слива — лендинг студии маникюра

Прототип одностраничного сайта студии маникюра.

## Как открыть
Скачайте репозиторий и откройте `index.html` в браузере — сервер не нужен.

## Что внутри
- `index.html` — разметка и стили (картинки встроены в файл).
- `script.js` — анимации, палитра, отзывы, форма записи, логгер.
- `fonts/` — шрифты Yeseva One, Onest, IBM Plex Mono (лицензия SIL OFL 1.1). Хранятся локально, браузер не обращается к Google.
- `photos/` — исходные фото: рука на первом экране, мастера, клиентки.

## Безопасность
- Content-Security-Policy в `<head>`: скрипты, шрифты и картинки загружаются только с этого сайта.
- Текст из формы выводится через `textContent`, без `innerHTML`.
- Когда подключите отправку заявок на свой сервер, добавьте его адрес в `connect-src`.

## Перед запуском
- Отзывы и имена — примеры. Замените их настоящими, с согласия клиенток.
- Форма записи пока никуда не отправляет заявки.
- Нужна страница политики обработки персональных данных и отдельное согласие в форме.
